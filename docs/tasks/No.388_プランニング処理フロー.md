
## 2. 区間の計算（planSegment）

出発地 → スポット1、スポット間、最終スポット → 目的地のすべてでこの処理を使う。

```mermaid
flowchart TD
  S["区間開始<br>現在時刻（通算分）"] --> R["直接手段を取得<br>プランで選んだ 徒歩 / 自転車 / 車 を getRoute"]
  R --> Q{"両端に最寄駅がある？"}
  Q -- 両端あり --> N["最寄駅ルートを 1 回だけ計算<br>駅到着 = 現在時刻 + 出発側の徒歩時間<br>発車 = 出発側ノードの候補から選択<br>所要 = 徒歩 + 待ち + 出発側の乗車時間 + 到着側の徒歩時間"]
  Q -- 片側だけ --> O["NEAREST_STATION_ONE_SIDE 警告<br>この区間の長距離徒歩メッセージは出さない"]
  Q -- どちらも無し --> SEL
  N --> SEL{"どれを選ぶ？"}
  O --> SEL
  SEL -- "優先手段が徒歩・自転車・車で取得できた" --> P["優先手段を選ぶ"]
  SEL -- "それ以外で最寄駅ルートがある" --> T["最寄駅経由（ID 4）を選ぶ"]
  SEL -- "それ以外" --> PR["優先度が最も高い手段<br>車、自転車、徒歩の順"]
  SEL -- "1 件も取れない" --> W["徒歩で再取得<br>失敗なら距離 0・所要 0"]
  P --> ALT
  T --> ALT
  PR --> ALT
  W --> ALT
  ALT["候補一覧を作る<br>選んだ手段 + 取得できた他の手段 + 最寄駅ルート（あれば必ず）"] --> M["メッセージ<br>取得失敗 / 徒歩フォールバック / 発車時間の補正 / 長距離徒歩"]
  M --> U["移動時間を出発側ノードへ書き戻す<br>現在時刻 += 移動時間"]
```

### 発車時間の選び方

| 条件 | 採用する発車時間 | メッセージ |
| --- | --- | --- |
| 出発側ノードの候補に「駅到着 + 1分」以降がある | その中で最も早いもの | なし |
| 候補が空で、前回採用した発車時間がある | 前回の発車時間を候補として同じルールで選ぶ | なし（前回の時刻が過去なら補正の警告） |
| 候補が空で、前回の発車時間も無い | 駅到着 + 1分 | 発車時間未入力の警告 |
| 候補がすべて「駅到着 + 1分」より前 | 駅到着 + 1分 | 発車時間補正の警告 |

- 候補は**出発側ノード**のもの（出発地 → スポット1 は出発地、スポット間は前のスポット、最終スポット → 目的地は最終スポット）。
- ノードに保存する `scheduledDepartureTimes` はユーザーが入力した配列のまま。書き戻すのは採用した `scheduledDepartureTime` と `waitingTime` だけ。

## 3. 再プランニング時の優先手段（buildPreferredSelections）

```mermaid
flowchart TD
  A["区間ごとに判定"] --> B{"前回結果に同じ区間の組がある？<br>出発側 ID と到着側 ID が一致"}
  B -- "前回結果そのものが無い" --> B2["ノードの transportMethodId を使う<br>保存済みプランを開いた直後など"]
  B -- 無い --> X["優先手段なし<br>自動選択"]
  B -- ある --> C["前回選んだ手段と発車時間を候補にする"]
  B2 --> D
  C --> D{"手段は有効？"}
  D -- "0 / 未設定" --> X
  D -- "徒歩・自転車・車だが、プランの移動手段に含まれない" --> X
  D -- "最寄駅（4）だが、両端に最寄駅が無い" --> X
  D -- 有効 --> E{"前回の候補に最寄駅（4）が無く、<br>今回は両端に最寄駅がある？"}
  E -- Yes --> X
  E -- No --> Y["優先手段として渡す<br>最寄駅なら発車時間も渡す"]
```

## 4. メッセージ一覧（見直し後）

| 優先度 | 種別 | レベル | 表示 | 保存 |
| --- | --- | --- | --- | --- |
| 0 | `DAY_OVERFLOW` 到着が 23:59 を超える | エラー | 赤枠 | できない |
| 1 | `OVER_TIME` 到着時間を超過 | 警告 | 黄色枠 | できる |
| 2 | `ROUTE_FETCH_FAILED` ルート取得失敗 | 警告 | 黄色枠 | できる |
| 3 | `ROUTE_FALLBACK_WALKING` 徒歩にフォールバック | 警告 | 黄色枠 | できる |
| 4 | `DEPARTURE_CANDIDATE_ADJUSTED` 発車時間を補正 | 警告 | 黄色枠 | できる |
| 5 | `DEPARTURE_CANDIDATE_EMPTY` 発車時間が未入力 | 警告 | 黄色枠 | できる |
| 6 | `NEAREST_STATION_ONE_SIDE` 片側だけ最寄駅 | 警告 | 黄色枠 | できる |
| 7 | `LONG_WALK_RECOMMENDATION` 徒歩で 1.5km 以上 | 警告 | 黄色枠 | できる |
| 8 | `EXTRA_TIME` 余裕時間の提案 | 情報 | 青枠 | できる |

- エラーが 1 件でもある日程があると、プレビューに「エラーがあるため、このプランニング結果は保存できません。」を表示し、保存ボタンを押してもトーストを出して保存しない。
