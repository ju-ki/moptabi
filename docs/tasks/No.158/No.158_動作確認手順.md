# No.158 営業時間の制御 動作確認手順

## 前提

- `make up` で DB を起動し、`frontend` / `backend` を起動しておく。
- 確認に使うスポットの例（営業時間は確認時点の Google マップで事前に確かめ、結果欄に記録する）。

| 種別 | 条件 | 例 |
|---|---|---|
| A: 定休日あり | 特定の曜日が休み | 月曜休館の美術館・博物館 |
| B: 昼休憩あり | 1 日に営業枠が 2 つ | ランチとディナーで分かれる飲食店 |
| C: 日跨ぎ営業 | 深夜 0 時を越えて営業 | 深夜営業のバー |
| D: 24 時間営業 | 終日営業 | コンビニ |
| E: 営業時間情報なし | Google マップに営業時間がない | 公園・神社 |
| F: 臨時休業 / 閉業 | Google マップで休業・閉業表示 | 検索で見つかったもの |

計画日は、A の定休日の曜日になる日付と、営業日になる日付の 2 つを用意する。

## 1. スポット検索（R1・R2・R6・R7）

| No | 手順 | 期待結果 | 結果 |
|---|---|---|---|
| 1-1 | A の定休日を計画日にして「観光地を選択」から A を Google 検索する | カードに「定休日の可能性」バッジと「この日(曜日)の営業時間: 定休日」が出る | |
| 1-2 | A の営業日を計画日にして同じ検索をする | バッジは出ず、その曜日の営業時間が 1 行で出る | |
| 1-3 | E を検索する | バッジも営業時間の 1 行も出ない | |
| 1-4 | F を検索する | 「臨時休業中」または「閉業」バッジが出る | |
| 1-5 | 1-1 の条件で「計画日に営業しているスポットのみ」を ON にして再検索する | A と F が一覧から消え、E は残る | |
| 1-6 | 該当がなくなる条件で 1-5 を行う | 「計画日に営業しているスポットが見つかりませんでした」が出る | |
| 1-7 | 行きたいリスト・過去のスポットのタブで A を含む状態にして 1-1・1-5 を行う | Google 検索と同じバッジ表示と絞り込みになる | |

## 3. プランニング（R3・R4・R8）

| No | 手順 | 期待結果 | 結果 |
|---|---|---|---|
| 3-1 | A を定休日に入れてプランニングを実行する | 警告一覧に「…定休日の可能性があります。公式サイト等で営業日をご確認ください。」が出る。カードの枠がアンバーになり「定休日の可能性」バッジが出る | |
| 3-2 | B を昼休憩をまたぐ滞在時間にしてプランニングする | 「…営業時間外の時間帯が含まれています（この日の営業時間: …）」が出て、カードに「営業時間外の可能性」バッジが出る | |

| 3-5 | D・E を入れてプランニングする | 警告は出ない | |
| 3-6 | 警告メッセージの並び順を見る | 到着時間超過の次に営業時間の警告が並ぶ | |
| 3-7 | 3-1 の状態のままプランを保存する | 警告があっても保存できる | |
| 3-8 | 営業時間の 1 行表示とアコーディオンを確認する | 「祝日の営業は判定していません」を含む注記が出る | |
| 3-9 | 公式サイトがあるスポットで警告を出す | カードの警告に「公式サイトを開く」リンクがあり、別タブで開く | |
