# No.439 カレンダー選択のレイアウトが動的になってしまっている 実装計画

調査対象: `dev` (0a82bda)

## 1. 要件（Issue #439）

- 開始日・終了日を選ぶとき、ヒントのメッセージによってカレンダーの幅が変わり押しづらい
- メッセージの幅に関わらず、カレンダーの幅は固定とする

## 2. 原因

`frontend/src/components/DateRangePicker.tsx`

- ポップオーバーが `PopoverContent className="w-auto p-0"` のため、幅が中身の最大幅で決まる。
- 中身はヒント（`getHintMessage()`）とカレンダー。ヒントは選択状態で4種類に切り替わり、文字数が 16〜29 文字と違う。
- カレンダー1か月分の幅は 7列 × 36px（`w-9`）+ 左右 padding 24px（`p-3`）= 276px。ヒントが長いとき（例:「終了日を選ぶか、同じ日を選んで「日帰り」にしてください」≒ 29文字 × 12px + 24px ≒ 372px）はポップオーバーがヒントに合わせて広がる。
- カレンダー（`ui/calendar.tsx`）は前月/翌月ボタンが `absolute left-1` / `absolute right-1` のため、ポップオーバーの幅が変わるとボタンの位置が動く。日付のグリッドは左寄せのままなので、選択のたびに見た目が崩れる。

| 選択状態 | ヒント | ポップオーバーの幅 |
| --- | --- | --- |
| 未選択 | 開始日を選んでください（最大 7 日間） | ヒント幅（約 290px） |
| 開始日のみ | 終了日を選ぶか、同じ日を選んで「日帰り」にしてください | ヒント幅（約 370px） |
| 日帰り | 同じ日を選ぶと選択を解除できます | カレンダー幅（約 278px） |
| 複数日 | 日付を減らすには、開始または終了日を選択してください | ヒント幅（約 340px） |

## 3. 方針

`DateRangePicker.tsx` だけを変更する。共通の `ui/popover.tsx` / `ui/calendar.tsx` は他画面でも使っているため変えない。

1. **ポップオーバーの幅を固定**: `PopoverContent` の `w-auto` を `w-[278px]` に変える。
   - 276px（カレンダー1か月分）+ 枠線 2px（`border` 左右、`box-sizing: border-box`）。
   - 定数のクラス名はコメントで内訳を書く。
2. **ヒントは固定幅の中で折り返す**: 長いヒントは2行に折り返す（日本語は標準で折り返される）。
3. **ヒントの高さを2行分に固定**: 折り返しで行数が 1↔2 行と変わると、カレンダーが上下に動いて同じく押しづらくなるため、ヒント文に `min-h-8`（text-xs の行高 1rem × 2行）を付ける。2行を超える文言は現状ない（最長 29 文字、1行あたり約 21 文字）。

モバイル（幅 360px 程度）でも 278px は画面内に収まる。
