# No.439 カレンダーの幅固定 動作確認手順

前提: ログイン済み。スマートフォン幅（DevTools で 375px 程度）と PC 幅の両方で確認する。

| No | 手順 | 期待結果 | 結果 |
| --- | --- | --- | --- |
| 1 | `/plan/create` を開き、予定日ボタンを押す（開始日のみ選択済み） | カレンダーが開き、ヒントは1行で表示される。カレンダーの日付はポップオーバーの幅いっぱいに均等に並ぶ | |
| 2 | 終了日を選ぶ（複数日） | ヒントが「日付を減らすには…」に変わるが、カレンダーの幅・位置・前月/翌月ボタンの位置は変わらない | |
| 3 | 開始日と同じ日を選び直して日帰りにする | ヒントが「同じ日を選ぶと選択を解除できます」に変わるが、カレンダーの幅・位置は変わらない | |
| 4 | 同じ日をもう一度選んで選択を解除する（未選択） | ヒントが「開始日を選んでください（最大 7 日間）」に変わるが、カレンダーの幅・位置は変わらない | |
| 5 | No.1〜4 の間、前月/翌月ボタンを続けて押す | ボタンの位置が動かず、続けて押せる | |
| 6 | 日数を減らして確認ダイアログを出す | ダイアログが従来どおり表示され、削除・キャンセルが動く | |
| 7 | 既存プランの編集画面 `/plan/[id]/edit` で予定日を開く | No.1〜5 と同じく幅が固定されている | |
| 8 | スマートフォン幅（375px）で開く | カレンダーが画面内に収まる | |
