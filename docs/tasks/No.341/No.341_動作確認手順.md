# No.341 地図からスポットを探す 動作確認手順

- 実装計画: [No.341_実装計画.md](./No.341_実装計画.md)

## 前提

- `make up` で DB を起動し、frontend・backend を起動してログインする。
- 確認用のプランを作る: 計画日は 2 日（1 日目が土曜）、出発地・目的地は京都駅、1 日目に清水寺と伏見稲荷大社、2 日目に嵐山を登録。
- 行きたいリストに京都市内のスポットを数件登録する（うち 1 件は月曜休館の施設。例: 京都国立博物館）。
- 定休日の確認用に、上とは別に **計画日が月曜** の1日プラン（出発地・目的地は京都駅）を作る。3-6、4-2、4-4 はこの月曜プランで確認する。
- 過去のスポットの確認用に、訪問済みのスポットが 21 件以上ある状態にする（4-8 で使う）。
- PC（幅 1280px 以上）とスマホ幅（390px、ブラウザの開発者ツール）の両方で確認する。

## 1. 2段構成（Step 1）

| No | 操作 | 期待結果 | 結果 |
|---|---|---|---|
| 1-1 | プラン作成画面で「観光地を選択」を押す | ダイアログ上部に「リストで探す / 地図で探す」が出て、リストで探すが選ばれている |  |
| 1-2 | リストで探すのまま3タブを切り替える | 「計画日に営業しているスポットのみ」は2段目タブの上に1つだけあり、どのタブでも同じ状態 |  |
| 1-3 | 地図で探すに切り替えてダイアログを閉じ、もう一度開く | 地図で探すで開く |  |
| 1-4 | Google 検索タブでプランの地点を2つ選んだあと、別の日の「観光地を選択」を開く | 地点の選択が外れている（P-5） |  |
| 1-5 | Google 検索タブで「地図で位置を調整」を開く | 検索範囲の円が薄く、地図の POI が読める（P-6） |  |
| 1-6 | スマホ幅でダイアログを開く | 画面全体に表示され、角丸・余白がない |  |

## 2. 中心点（Step 2）

| No | 操作 | 期待結果 | 結果 |
|---|---|---|---|
| 2-1 | 地図で探すを開く | 目的地（京都駅）を中心に表示。S/G と ①清水寺 ②伏見稲荷大社のピンが出る。開いただけでは Places API が呼ばれない（開発者ツールの Network で確認） |  |
| 2-2 | PC で候補チップ「① 清水寺」を押す | 清水寺へ移動し、街歩きの縮尺（ズーム 15 前後）になる |  |
| 2-3 | 候補チップ「10/19 嵐山」を押す | 嵐山へ移動する |  |
| 2-4 | スマホ幅で住所欄をタップ | 候補（出発地・目的地・各スポット・現在地）がリストで出る。地図上に候補チップの行は常時出ていない |  |
| 2-5 | 住所欄に「函館市元町」と入れて Enter | 函館へ移動する。同じ住所でもう一度 Enter しても Geocoding は呼ばれない |  |
| 2-6 | 存在しない住所を入れて Enter | エラーが出て、中心は動かない |  |
| 2-7 | 「現在地」を押す（位置情報を許可） | 現在地へ移動する。拒否したときはエラー文言が出る |  |
| 2-8 | 地図で探すを開いただけの状態 | 位置情報の許可ダイアログは出ない |  |

## 3. POI の選択と追加（Step 3）

| No | 操作 | 期待結果 | 結果 |
|---|---|---|---|
| 3-1 | 清水寺を中心にして、地図上の Google の POI（例: 八坂神社）を押す | Google 標準の吹き出しは出ず、選択中スポットのカード（スマホは下部シート）が出る |  |
| 3-2 | 同じ POI をもう一度押す | Place Details の通信が発生しない |  |
| 3-3 | カードの表示（スマホ） | 名前・バッジ、「★評価 ・ ① 清水寺から○○km ・ 営業時間」の1行、追加ボタンの3段だけ |  |
| 3-4 | カードの表示（PC） | 住所、「① 清水寺から約○○km」、計画日の営業時間、祝日の注記が出る |  |
| 3-5 | 地図をドラッグしてから POI を押す | 距離が「中心から○○km」になる |  |
| 3-6 | 計画日に休みの POI を押す | 「休み」系のバッジと短い文言が出る。追加はできる |  |
| 3-7 | 「計画に追加」を押す | ダイアログは閉じず、その位置に番号ピンが出る。カードは「追加しました」「取り消す」になる。休みのスポットなら確認トーストが出る |  |
| 3-8 | 「取り消す」を押す | 番号ピンが消え、カードは「計画に追加」に戻る |  |
| 3-9 | 追加済みスポットの番号ピンを押す | カードに「選択解除」が出て、押すとプランから外れる |  |
| 3-10 | その日のスポットを上限まで追加してから POI を押す | 「計画に追加」が押せず、上限の文言が出る |  |

## 4. 行きたいリスト・過去のスポットのピン（Step 4）

| No | 操作 | 期待結果 | 結果 |
|---|---|---|---|
| 4-1 | 初めて地図で探すを開く | 行きたいリスト・過去のスポットのピンは出ていない（行きたいリストの取得通信も発生しない） |  |
| 4-2 | PC の「表示するピン」で行きたいリストを ON / スマホは「ピン」ボタン → シートで ON | ハートのピンが出る。定休日のスポットは薄く表示される |  |
| 4-3 | ダイアログを閉じて開き直す、またはページを再読み込みする | 行きたいリストは ON のまま |  |
| 4-4 | 「計画日に休みのピンを隠す」を ON | 薄いピンが消える。リストで探すに戻ると「計画日に営業しているスポットのみ」も ON になっている |  |
| 4-5 | ハートのピンを押す | 取得済みデータでカードが出る（Place Details の追加通信なし）。追加できる |  |
| 4-6 | プランの伏見稲荷大社の滞在時間を営業時間外にする | 地図の ② ピンに「営業時間外」の印が付く |  |
| 4-7 | プライベートブラウズ等で localStorage が使えない状態で開く | エラーにならず、ピンは OFF の既定で動く |  |
| 4-8 | 座標キャッシュを消した状態（localStorage の `place_latlng_` を削除）で過去のスポットを ON | Place Details の通信は 20 件で止まり、「位置を取得していないスポットが n 件」と「さらに表示」が出る。押すと次の 20 件を取得する |  |
| 4-9 | 4-8 のあと、ダイアログを閉じて開き直して過去のスポットを ON | 座標キャッシュがあるスポットは通信なしでピンが出る |  |

## 5. スクリーンショット

- PC: リストで探す、地図で探す（POI 選択中）
- スマホ: リストで探す、地図で探す（POI 選択中）、表示するピンのシート、上限到達時
