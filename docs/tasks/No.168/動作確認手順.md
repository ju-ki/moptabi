# No.168 現在地登録の秘匿化 動作確認手順

## 前提
- ローカル DB を起動済み（`make up`）
- `backend/.dev.vars` と `backend/.env` に `LOCATION_ENCRYPTION_KEY` を設定済み（`openssl rand -base64 32` で作成）
- DB の中身は `bun run db:studio` か `psql` で確認する

## フェーズ 1

| No | 手順 | 期待結果 | 結果 |
|---|---|---|---|
| 1 | マイページでお気に入り地点を登録する（ラベル「自宅」、最寄駅あり） | 一覧に登録した地点が表示され、地図のピン位置・ラベル・最寄駅が登録内容と一致する | |
