# No.409 予定日のデフォルト値 動作確認手順

前提: ログイン済み。確認日を「今日」とする。

| No | 手順 | 期待結果 | 結果 |
| --- | --- | --- | --- |
| 1 | `/plan/create` を開く | 予定日ボタンに翌日の日付（YYYY-MM-DD）だけが表示される | |
| 2 | 予定日ボタンを押してカレンダーを開く | 翌日の月が表示され、翌日が選択状態。ヒントは「終了日を選ぶか、同じ日を選んで「日帰り」にしてください」 | |
| 3 | 翌日以降の別の日を選ぶ | 「翌日 ~ 選んだ日」が表示され、日別タブが作られる | |
| 4 | 画面を開き直し、カレンダーで翌日（選択済みの日）をもう一度選ぶ | 日帰り（翌日 ~ 翌日）になり、タブが1つ作られる | |
| 5 | 画面を開き直し、終了日を選ばずに保存する | 「プランの日付を入力してください」が表示され保存されない | |
| 6 | 月末の日に `/plan/create` を開く（端末の日付を変更して確認） | 翌月1日が開始日に入る | |
| 7 | 別画面へ移動してから `/plan/create` に戻る | 毎回、その時点の翌日が開始日に入る | |
| 8 | 既存プランの編集画面 `/plan/[id]/edit` を開く | 既存プランの開始日・終了日がそのまま表示される（翌日に変わらない） | |
| 9 | プランを作成して保存した後、もう一度 `/plan/create` を開く | 翌日が開始日に入っている | |
