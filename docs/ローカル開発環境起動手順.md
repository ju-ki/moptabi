# ローカル開発環境 起動手順

## 方法1: 通常の開発サーバー（推奨）

### 1. バックエンドの起動
```bash
cd backend
bun run dev
```
→ http://localhost:8787 で起動

### 2. フロントエンドの起動
```bash
cd frontend  
pnpm run dev
```
→ http://localhost:3000 で起動

この方法では、`.env.local`の`NEXT_PUBLIC_API_BASE_URL`を以下に設定：
```
NEXT_PUBLIC_API_BASE_URL=http://localhost:8787/api
```

---

## 方法2: Cloudflare Workers環境（wrangler dev）

### 事前準備
フロント側のビルドが必要：
```bash
cd frontend
pnpm run wrangler:dev
```

### 1. バックエンドの起動
```bash
cd backend
bun run wrangler:dev
```
→ http://localhost:8787 で起動
※ログに "Ready on http://..." と表示されることを確認

### 2. DBの設定(Staging)
neon環境に繋ぎたいのでdev.varsにステージングのDATABASE_URLを貼り付ける

## 推奨設定

**ローカル開発には「方法1: 通常の開発サーバー」を推奨します。**
- 起動が早い
- ホットリロードが確実に動作
- デバッグが容易

**Cloudflare Workers環境（方法2）は、本番でしか再現しないエラーが出てきた際に使用(neon-http関係?)。**
