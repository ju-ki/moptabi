# プランリストページ（/plan/list）

## 概要

ユーザーが作成した旅程プランの一覧を表示するページ。プランの検索・フィルタリング・並び替え機能を提供する。

## 主要コンポーネント一覧

| コンポーネント | 役割 |
|---|---|
| `TripCard` | プラン一覧の各プランカード表示 |
| `TripSearchForm` | プラン名・日付等による検索フォーム |
| `DateRangePicker` | 旅行日程の日付範囲を選択するピッカー |

## テスト対象仕様

### TripCard（未テスト → Phase 4 Highで追加）

| 状態・操作 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | プランデータあり | プラン名・旅行日程・スポット数・サムネイル画像が表示される |
| 初期表示 | サムネイルなし | デフォルト画像が表示される |
| プランクリック | カードクリック | プラン詳細ページに遷移する |
| 削除 | 削除ボタンクリック | 削除確認ダイアログが表示される |

### TripSearchForm（未テスト → Phase 4 Lowで追加）

| 状態・操作 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | 任意 | 検索フォームが表示される |
| 検索入力 | テキスト入力 | 入力値がフィルタリング条件に反映される |
| 検索クリア | クリアボタンクリック | 検索条件がリセットされる |

### DateRangePicker（未テスト → Phase 4 Lowで追加）

| 状態・操作 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | 任意 | 日付ピッカーが表示される |
| 日付選択 | 開始日・終了日を選択 | 選択した日付範囲がコールバックで返される |
| 無効な範囲 | 終了日 < 開始日 | エラー表示またはバリデーション処理が行われる |
| クリア | クリアボタンクリック | 日付選択がリセットされる |
