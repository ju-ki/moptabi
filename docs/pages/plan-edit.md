# プラン編集ページ（/plan/[id]/edit）

## 概要
作成済みプランの内容を修正できるようにし、旅行計画の柔軟な変更を可能にする。


## 主要コンポーネント一覧

| コンポーネント | 役割 | 備考 |
|---|---|---|
| `TravelPlan` | プラン全体のコンテナ。DayPlan一覧・プラン保存ボタンを管理 |
| `DateRangePicker` | プランの開始日と終了日を選択できる |
| `DayPlan` | 1日分のプラン（スポット一覧・追加ボタン） |
| `Transportation` | プランニングで使用する移動手段を設定 | - |
| `Departure` | 出発地の表示・選択 |
| `Destination` | 目的地の表示・選択 |
| `DepartureAndDestination` | 出発地・目的地の連動ロジック（Zustandストア直接テスト） |
| `SpotCard` | プラン内のスポットカード表示・並び替え |
| `TimeSetting` | 出発時間と到着時間を入力する | 課題229で追加|
| `SpotSettingEditor` | PlanSpotSettingCard（並び替え・滞在時間・最寄駅・移動情報）とNearestStationDeparture, NearestStationDestinationを表示  | 課題229で追加|
| `PlanSpotSettingCard` | 観光スポットの優先順位・滞在時間・最寄駅・移動情報を設定できる | 課題229で追加|
| `NearestStationDeparture` | 最寄駅を設定できる | 課題229で追加|
| `NearestStationDestination` | 最寄駅を設定できる | 課題229で追加|
| `PlanningWarningList` | スポット間の距離等が離れていたりする場合のメッセージを表示する | 課題229で追加|
| `ArrivalTimeWarning` | プランニングした際に到着時間を超過するメッセージを表示 | 課題229で追加|
| `TimelineStatus` | プランニングした際に計算された出発時間と到着時間を表示する | 課題229で追加|
| `ExtraTimeSuggestions` | プランニング後、時間に余裕がある場合のメッセージを表示する | 課題229で追加|
| `CreatePlanButton` | プランの保存ボタン |
| `PlanConsistencyAction` | 日付単位で再プランニング必要状態を表示し、復元操作を提供する | No.225で追加 |
| `SpotSelection` | スポット検索タブ（Google検索・行きたいリスト・過去スポット） | -|
| `PlanningButton` | 入力されたスポット情報等を元に滞在時間やルートの生成等を行う | -|
| `DepartureDetailCard` | プランニング後の出発地情報を表示する | 実装済み |
| `SpotDetailCard` | プランニング後の観光スポット詳細を表示する | 実装済み |
| `DestinationDetailCard` | プランニング後の目的地情報を表示する | 実装済み |
| `TravelMap` | プランニング後のスポットとルートを地図上に表示する, DistanceInfo(移動時間や移動手段、移動距離を表示) | 実装済み |

## 対象仕様

### TravelPlan

| 状態・操作 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | プランデータあり | プランタイトル・日程タブ・DayPlan一覧が表示される |
| 日程なし | 日程数0 | 空状態のメッセージが表示される |
| プラン保存 | 保存ボタンクリックかつdirty日付なし | 保存処理が呼ばれる |
| プラン保存（ブロック） | 保存ボタンクリックかつdirty日付あり | 保存処理を呼ばず、固定文言を表示する |

### DateRangePicker

| 状態・操作 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | - | DBから取得した開始日と終了日が表示され、選択された状態 |
| 選択操作 | 日付を延長する | 新規で空のプランデータができる |
| 選択操作 | 日付を短縮する | 確認ダイアログを表示する |
| 初期表示 | 日付を短縮する | 確認ダイアログに「○月○日のプランが削除されます。よろしいですか？」(複数日ある場合は","区切り)というメッセージと、削除とキャンセルボタンが表示される |
| 選択操作 | 削除ボタンを押下 | 日付の短縮が行われ、該当日のプランデータが削除される |
| 選択操作 | キャンセルボタンを押下 | 日付の短縮がキャンセルされ、該当日のプランデータが削除されない |

### DayPlan

| 状態・操作 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | 日付・スポットデータあり | 日付・スポットカード一覧が表示される |
| スポットなし | スポット数0 | 空状態が表示される |
| スポット追加ボタン | スポット上限未満 | スポット追加ボタンが有効 |
| スポット追加ボタン | スポット上限達成 | スポット追加ボタンが無効 |
| スポットを追加 | 追加ボタンクリック | SpotSelectionモーダルが開く |
| 整合性導線表示（初期） | プランニング未実行 | 日付単位の整合性導線は非表示 |
| 整合性導線表示（プランニング後） | プランニング実行済み | 日付単位の整合性導線（復元操作を含む）が表示される |
| dirty状態遷移 | スポット追加/削除/並び替え/プランニング影響項目の編集 | 対象日付が再プランニング必要状態になる |
| dirty状態非遷移 | spot.memo のみ編集 | 対象日付は再プランニング必要状態にならない |
| 復元操作 | 日付単位導線から復元を押下 | 対象日付のスポット情報が前回プランニング時点に戻る |

### Transportation
| 状態・操作 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | - | 全て未選択 |
| 初期表示 | - |  未選択の場合は徒歩が選択されますの注意書きが表示されている|
| 任意の移動手段をクリック | チェックがoffになっている移動手段をクリック | チェックボックスがonになる |
| 任意の移動手段をクリック | チェックがonになっている移動手段をクリック | チェックボックスがoffになる |
| 任意の移動手段をクリック(複数) | チェックがoffになっている移動手段をクリック | チェックボックスがonになる <br>他の移動手段のチェック状態に影響が出ていない |
| 任意の移動手段をクリック(複数) | チェックがonになっている移動手段をクリック | チェックボックスがoffになる <br>他の移動手段のチェック状態に影響が出ていない |

### Departure / Destination

| イベント概要 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | - | DBに登録されている地点が選択されている |
| 選択操作 | セレクトから地点を選択 | ストアの地点情報が更新される |
| 選択操作 | 地点の名前変更 | ストアの名前が更新される |
| 選択操作 | 出発時間/到着時間の選択 | ストアの時間が更新される |
| 選択操作 | 住所検索 | ストアの地点情報が更新される |
| 選択操作 | 観光スポット周辺から地点を選択(観光スポットなし) | 非活性 |
| 選択操作 | 観光スポット周辺から地点を選択(観光スポットあり) | 活性<br>プルダウンから観光スポットの情報を選択可能 <br> スポット選択後スッポット同じ座標にストアが更新される |
| 選択操作 | 現在地をもとに設定する | 押下することで、現在地の座標にストアが更新される |

### TimeSetting

| イベント概要 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | - | typeがdepartureなら出発時間、destinationなら到着時間で表示される |
| 初期表示(デフォルト値) | - | DBに登録されているtimeが表示される |
| 選択操作 | - | typeがdepartureなら出発時間のストア、destinationなら到着時間のストアが更新される|

### SpotSettingEditor

| イベント概要 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 初期表示 | スポット数(出発地と目的地は除く)が0件 | スポットが選択されていません<br>スポットを追加してくださいというメッセージが表示 |
| 初期表示 | スポット数(出発地と目的地は除く)が1件以上 | NearestStationDeparture, NearestStationDestination, PlanSpotSettingCardを表示 |
| 並び替え(ドラッグ&ドロップ) | スポット数(出発地と目的地は除く)が2件以上 | ドロップ後に順番が再計算され、ストアのorderが更新される |
| 並び替え(プルダウン) | スポット数(出発地と目的地は除く)が2件以上 | 選択した順番に合わせて、対象スポットと他スポットのorderが更新される |
| スポット削除 | 削除ボタン押下 | 対象スポットが削除され、後続スポットのorderが繰り上がる |

### DepartureAndDestination

| テストグループ | 確認内容 |
|---|---|
| 初期値の確認 | 単一日/複数日プランでの初期値のデフォルト設定 |
| スポット情報の保持 | 出発地・目的地選択時の地点情報更新 |
| 単一日の連動確認 | 出発地変更→目的地が連動。目的地変更→出発地が連動,ただし出発時間と到着時間は連動させない |
| 複数日の連動確認 | 目的地変更→翌日出発地が連動。出発地変更→前日目的地は不変,ただし出発時間と到着時間は連動させない |

### PlanningButton
| 項目 | 内容 |
|---|---|
| 機能 | 計画のプレビューを行うボタン |
| 主な処理 | ルート生成、所要時間計算、出発/到着時間の算出、最寄駅を考慮した時間調整 |

### 画面初期化

| 状態・操作 | 入力条件 | 期待する出力・動作 |
|---|---|---|
| 画面離脱時 | `/plan/[id]/edit` から他画面へ遷移 | プラン編集ストアが初期化される |
| 保存成功時 | 保存API成功後に詳細画面へ遷移 | 遷移前にプラン作成用ストアが初期化される |
| 再アクセス時 | 初期化後に `/plan/[id]/edit` へ再アクセス | 前回の入力値は表示されず、前回DBに登録時点の初期状態で表示される,取得したデータを元にプランニングした状態で表示を行う |
| 再アクセス時（デフォルト地点） | 候補取得処理が完了 | DBに登録されている値が再設定される |

### 保存整合性制御

| 項目 | 条件 | 期待する出力・動作 |
|---|---|---|
| dirty管理単位 | - | 日付単位で管理する |
| dirty付与条件 | スポット追加/削除/並び替え | 対象日付をdirtyにする |
| dirty付与条件 | プランニングに影響する項目（order, stayDuration/stayStart/stayEnd, nearestStation, routeToNext）編集 | 対象日付をdirtyにする |
| dirty付与条件 | プレビューで出発地/スポット/目的地の移動手段候補を切り替え | 対象日付をdirtyにする |
| dirty除外条件 | spot.memoのみ編集 | dirtyにしない |
| dirty解除条件 | 対象日付の再プランニング成功 | 対象日付のみdirty解除 |
| dirty解除条件 | 対象日付の復元操作成功 | 対象日付のみdirty解除 |
| 保存ブロック | dirty日付が1つ以上存在 | 保存APIを呼ばず、固定文言を表示する |
| 固定文言（タイトル） | 保存ブロック時 | プランニング結果が最新ではありません |
| 固定文言（本文） | 保存ブロック時 | スポット内容が変更されたため、このままでは保存できません。再プランニングを実行するか、前回のプランニング結果に戻してください。 |

補足:
- 復元対象はスポット情報のみとする。
- nearestStationは変更後も既存値を保持し、自動再計算しない。

#### 再プランニング時の移動手段優先ルール
| ルール | 内容 |
|---|---|
| 区間優先の採用 | プレビュー(DB)で選択済みの移動手段（出発地→最初のスポット、スポット間、最後のスポット→目的地）を再プランニング時に優先採用する |
| 最寄駅区間の扱い | 最寄駅経由（TRANSIT）が選択済みであれば最寄駅経由を優先採用する |
| 直接移動の扱い | 車/自転車/徒歩が選択済みであれば、最寄駅が利用可能でも選択済み手段を優先採用する |
| フォールバック | 選択済み手段でルート取得できない場合は既存ルール（取得可能な代替手段）へフォールバックする |

#### 出発地と目的地の入力パターンによるアルゴリズム
| ケース | アルゴリズム | 期待する出力・動作 |
|---|---|---|
| 出発時間・到着時間が両方入力済み | 1. 出発時間起点で、最初のスポットまでのルートと所要時間を取得<br>2. 取得結果をもとに各スポット滞在時間を更新しつつ目的地まで繰り返す<br>3. 最寄駅設定がある区間は最寄駅を経由したルートで計算　<br>4. 最寄駅情報の移動時間および発車時間が入力されている場合は、その時間を考慮して時間計算を行う | 到着時間超過時は警告を表示し、出発時間をどれだけ早めるか、または滞在時間をどれだけ短縮するかを提案する。余裕がある場合は余裕時間提案を表示する |
| 出発時間のみ入力済み（到着時間未入力） | 1. 出発時間起点でルートと所要時間を順次取得<br>2. 取得結果をもとに滞在時間を更新しつつ目的地まで繰り返す<br>3. 最寄駅設定がある区間は最寄駅を経由したルートで計算<br>4. 最寄駅情報の移動時間および発車時間が入力されている場合は、その時間を考慮して時間計算を行う | 最終的な到着時間を算出して表示する |
| 到着時間のみ入力済み（出発時間未入力） | 1. 到着時間起点で逆順にルートと所要時間を順次取得<br>2. 取得結果をもとに滞在時間を更新しつつ出発地まで繰り返す<br>3. 最寄駅設定がある区間は最寄駅を経由したルートで計算　<br>4. 最寄駅情報の移動時間および発車時間が入力されている場合は、その時間を考慮して時間計算を行う | 最終的な出発時間を算出して表示する |
| 出発時間・到着時間が両方未入力 | - | 本ケースはバリデーションでエラーとする |

#### 発車時間の多重候補管理と選択ルール

**概要**  
各区間（出発地→最初のスポット/スポット間/最後のスポット→目的地）において、複数の発車時間候補を最大3つまで保持し、プランニング時に最適な候補を選択する仕組み。

| 項目 | 内容 |
|---|---|
| 候補の最大数 | 3つまで |
| ユーザー入力 | 発車時間は**必須ではない** |
| 入力方法 | 区間ごとに最大3つの発車時間を手入力（複数選択で優先順位は自動判定） |

**発車時間候補の選択ルール**

| 条件 | 動作 | 表示 |
|---|---|---|
| 最寄駅到着時間+1分以降で発車時間候補がいずれか存在 | その中で**最も早い時間**を採用 | - |
| 発車時間が未入力 | 最寄駅到着時間+1分を自動配置 | 注意喚起メッセージ（「発車時間が未入力のため、最寄駅到着の1分後に設定しました。」） |
| 入力した候補すべてが「最寄駅到着時間+1分」より前（過去） | 最寄駅到着時間+1分を自動配置 | 警告メッセージ（「入力した発車時間が最寄駅到着時間より前になるため、発車時間を調整しました。発車時間の見直しまたはスポットの見直しを行ってください。」） |

**注意喚起と警告の表示位置**
- 区間ごとに明示的に表示（例：「〇〇駅 → ××スポット」の区間カードに該当メッセージを付記）
- 注意喚起: 情報アイコン + 淡い背景
- 警告: 警告アイコン + やや目立つ背景

**保存可能性**
- 注意喚起／警告が表示されていても、**プラン保存は常に可能**（制約なし）

#### 移動手段が徒歩でかつ距離が1.5km以上離れている際のメッセージ
| 条件 | メッセージ | 備考|
|---|---|---|
| 1.5kmかつ移動手段が徒歩 | :起点名から:目的地は徒歩でhh時間mm分かかるため,最寄駅を推奨します |時間が60分未満の場合はhh時間を表示しない|


#### 余裕時間に応じた提案メッセージ一覧
| 余裕時間 | 提案タイプ | 提案内容 |
|---|---|---|
| 30分以上 | EXTRA_TIME_SMALL | 滞在時間延長の提案（「お気に入りのスポットでもう少しゆっくり過ごしてみては？」） |
| 60分以上 | EXTRA_TIME_MEDIUM | ゆとりある観光の提案（「各スポットで約○※1分ずつ長く滞在できます」）※1 余力時間/スポット数 |
| 90分以上 | EXTRA_TIME_LARGE | スポット追加の積極的な提案（「新しいスポットを追加して、より充実した旅程にしませんか？」） |

#### 到着時間を超えた際の提案メッセージ一覧
| 余裕時間 | 提案タイプ | 提案内容 |
|---|---|---|
| 1分以上30分未満 | EXTRA_TIME_SMALL | 滞在時間をmm分減らしてみましょう。|
| 31分以上60分未満 | EXTRA_TIME_MEDIUM | 各スポットの滞在時間を減らすか他の移動手段を検討してみましょう|
| 61分以上 | EXTRA_TIME_LARGE | スポットの見直しをしてみましょう。 |

#### 最寄駅経由区間の内部時間計算ルール
| 項目 | 内容 |
|---|---|
| 計算式 | 駅まで徒歩 + 待機時間 + 駅間移動 + 駅から徒歩 |
| 待機時間のデフォルト | 待機時間が未設定の場合は 1 分として扱う |
| 負値対策 | 各要素は 0 未満にならないよう補正して計算する |

#### 移動手段複数設定時のルール
| ルール | 内容 |
|---|---|
| ルート選択 | 複数の移動手段が選択されている場合は、ルート情報が取得できる手段を優先して使用する |
| 優先順 |  徒歩 < 自転車 < 車 < 最寄駅を考慮した経路（右に行くほど優先度が高い） |
| 切り替え | 優先選択されなかった手段はプレビュー画面で切り替え可能 |
| フォールバック | 徒歩以外でルート取得できない場合は徒歩ルートを取得する |
| 取得失敗時 | 徒歩でも取得できない場合は「ルートを取得できませんでした。条件を変更してください」を表示する |
| 全手段取得失敗時の内部データ | プレビュー表示を継続するため、選択ルートの distance / duration は「不明」を保持して返却する |

| 移動手段切り替え | 選択操作 | 移動手段候補タップ | 表示上の移動手段と移動時間が即座に切り替わる（再計算なし） |
| 発車時間 | 初期表示 | 最寄駅設定済み / 発車時間が選択されている | 採用された発車時間を表示 |
| 発車時間候補 | 初期表示 | 最寄駅設定済み / 採用されなかった候補が存在（最寄駅到着時間+1分より後のもの） | 採用された発車時間の下に「他の候補：HH:mm, HH:mm」の形式で表示 |
| 発車時間切り替え | 選択操作 | 発車時間候補タップ | ストアの使用発車時間を更新する（再計算は行わない） |
| 地点名 | 初期表示 | 目的地あり | 目的地名を表示 |
| 住所 | 初期表示 | addressあり | 住所を表示 |
| 到着時刻 | 初期表示 | timeあり | 入力済みの到着時刻を表示 |

### TravelMap


#### 基本表示

| 項目名 | イベント概要 | 条件 | 期待する出力・動作 |
|---|---|---|---|
| 地図表示 | 初期表示 | 出発地・スポット・目的地あり | GoogleMap を表示 |
| マーカー（出発地） | 初期表示 | - | 出発地マーカーを表示（独自色） |
| マーカー（スポット） | 初期表示 | - | 各スポットのマーカーを表示（独自色） |
| マーカー（目的地） | 初期表示 | - | 目的地マーカーを表示（独自色） |
| マーカー（最寄駅） | 初期表示 | 最寄駅設定済みの区間あり | 最寄駅マーカーを表示（既存マーカーと同形状・最寄駅専用色）。同一最寄駅は区間ごとに重複表示せず1つに統合する |
| 情報ウィンドウ | 選択操作 | マーカー押下 | 該当地点名を表示 |
| ルート表示（最寄駅なし） | 初期表示 | ルート計算成功 / 最寄駅未設定区間 | 区間ごとのポリラインを RouteType に応じた色で表示 |
| ルート表示（最寄駅あり） | 初期表示 | ルート計算成功 / 最寄駅設定済み区間 | スポット→最寄駅（TO_STATION）、最寄駅→最寄駅（STATION_TO_STATION）の区間ポリラインを追加表示 |
| 移動手段反映 | 初期表示 | ルート計算成功 | 各区間の移動手段と移動時間をストアへ反映 |
| 距離情報 | 初期表示 | - | 右上コントロール領域にDistanceInfoを表示 |

#### ルートの種類と色定義

| RouteType | 区間 | 色 |
|---|---|---|
| `DEPARTURE_TO_SPOT` | 出発地 → スポット | `#34A853`（緑） |
| `SPOT_TO_SPOT` | スポット間 | `#4285F4`（青） |
| `SPOT_TO_DESTINATION` | スポット → 目的地 | `#FF0000`（赤） |
| `TO_STATION` | スポット/出発地/目的地 → 最寄駅（徒歩） | `#FACC15`（黄） |
| `STATION_TO_STATION` | 最寄駅 → 最寄駅（公共交通） | `#F97316`（オレンジ） |

#### DistanceInfo

| 項目名 | 条件 | 期待する出力・動作 |
|---|---|---|
| 最寄駅なし区間 | 最寄駅未設定 | 移動手段・移動時間・移動距離を1行で表示 |
| 最寄駅あり区間 | 最寄駅設定済み | 区間ごとに分割して「出発地→最寄駅（徒歩Xm） / 最寄駅→最寄駅（電車Y分） / 最寄駅→スポット（徒歩Zm）」のように列挙 |
| 距離・時間の算出元 | - | 基本的に Google Map の取得結果を使用する |

#### MapLegend（共通コンポーネント）

TravelMap および詳細画面で共通利用する凡例コンポーネント。地図の外側（下部）に別ブロックとして表示する。

| 凡例種別 | 表示内容 |
|---|---|
| マーカー種別 | 出発地 / スポット / 目的地 / 最寄駅 の各マーカー色とラベル |
| ルートカラー | DEPARTURE_TO_SPOT / SPOT_TO_SPOT / SPOT_TO_DESTINATION / TO_STATION / STATION_TO_STATION の各色とラベル |
